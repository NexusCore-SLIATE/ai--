# 🤖 ai-workspace

The centralized repository for the **Advanced Intelligence & Automation Track** at NexusCore-SLIATE. This workspace hosts modular conversational interfaces, context parsing scripts, and experimental natural language automation sandboxes.

---

## 📁 Workspace Matrix Structure

* 📁 **`ai-chatbot/`** — A frontend vanilla client implementation tracking automated onboarding queues to assist incoming ATI Badulla tech freshers.
* 📁 **`ai-model-experiments/`** — Python automation scripts, parsing logic collections, and context engineering templates used to explore structural text classification.

---

## 🛡️ Critical Security & Token Hygiene Regulations

As software engineering and cybersecurity tracks intersect here, active contributors must enforce strict operational safety measures:

1. **Absolute Zero Hardcoded Secrets:** Never commit private API orchestration keys, server access tokens, or administration strings directly into code files. 
2. **Environment Variable Enforcements:** All connection scripts must extract keys dynamically from environment states (`process.env` in JS, `os.environ` in Python).
3. **Data Anonymization Mandate:** When building datasets or evaluation scripts, ensure no personal student grading charts, system administration passwords, or sensitive credentials are leak-staged into experimental files.
